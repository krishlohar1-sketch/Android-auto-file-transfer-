How it works

Both phones need internet for connection setup. File data travels directly between browsers when the network allows it. A website cannot automatically turn on Wi-Fi, hotspot or permissions.

If connection fails, try both phones on the same Wi-Fi or mobile hotspot. Start with a small photo before trying large files.
